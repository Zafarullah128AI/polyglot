# Polyglot — Programming Language Identification from Code Snippets

**Prepared for Tarique Aziz (24BSIT118) — ML Exhibition Project**

## Problem statement

Developers, learners, and code-sharing platforms often deal with code snippets
that have no language label (pasted text, screenshots, old files). Polyglot is
an ML system that automatically identifies the programming language of a code
snippet using text-classification techniques, and compares models on accuracy
across snippet lengths.

## What it does

- **Identify** — paste any code snippet and get the detected language with a
  confidence score, top-3 candidates, and the individual votes of 3 models.
- **Model Arena** — 3 models compared head-to-head on the same hold-out test
  set, with a confusion matrix for the best model.
- **Length Lab** — accuracy of each model on short (1–3 lines), medium (4–10)
  and long (11+) snippets, from 5-fold cross-validation.
- **Dataset** — browse the dataset, add your own snippets (models retrain
  instantly), or bulk-upload a CSV (`language,code`).

No login, no accounts — a public lab tool. Open it and use it.

## Method

- **Features:** character n-grams (3–5, inside word boundaries) via TF-IDF.
  Code is identified by its shapes — `def`/`end`, `public class`,
  `#include`, `<?php`, `fn`/`let`, `package main` — and character n-grams
  capture punctuation and keyword shapes better than whole words.
- **Models (all three trained on the same data):**
  1. Logistic Regression (char TF-IDF + LR)
  2. Naive Bayes (char TF-IDF + MultinomialNB)
  3. Linear SVM (char TF-IDF + LinearSVC, calibrated for probabilities)
- **Evaluation:** stratified 80/20 hold-out split (seed 42) for headline
  metrics; 5-fold cross-validated predictions on the full dataset for the
  length-bucket analysis. Reproduce with `python evaluation.py`
  (writes `evaluation.json`).

## Measured results (200 snippets, 10 languages)

Hold-out test set (40 snippets):

| Model | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| Logistic Regression | **95.0%** | 96.0% | 95.0% | 94.9% |
| Linear SVM | **95.0%** | 96.0% | 95.0% | 94.9% |
| Naive Bayes | 85.0% | 87.0% | 85.0% | 84.7% |

Logistic Regression and Linear SVM tie at 95.0%; Logistic Regression is
reported as the best model (first on tie-break).

Accuracy by snippet length (5-fold CV):

| Model | Short (1–3 lines) | Medium (4–10) | Long (11+) |
|---|---|---|---|
| Logistic Regression | 81.0% (n=21) | 90.7% (n=118) | 96.7% (n=61) |
| Linear SVM | 85.7% (n=21) | 90.7% (n=118) | 96.7% (n=61) |
| Naive Bayes | 57.1% (n=21) | 81.4% (n=118) | 91.8% (n=61) |

Short snippets are the hardest, as expected — a one-line `print()` looks
similar in many languages. Longer snippets give the models more evidence.

Only 2 errors on the 40-snippet hold-out set, both understandable:
C# → Java (1) and TypeScript → JavaScript (1). TypeScript without type
annotations is syntactically identical to JavaScript, so that confusion is
inherent to the task.

## Dataset

`data.csv` — **200 snippets, 10 languages × 20 each** (Python, JavaScript,
TypeScript, Java, C, C++, C#, Go, Rust, PHP). Every snippet was written
originally for this project (see `build_data.py` to regenerate it).

This is a small demo dataset, sized for a class exhibition. For serious use,
upload a larger corpus through the Dataset tab (CSV with `language,code`
columns) — the app accepts any language present in the built-in list and
retrains all 3 models on the bigger dataset.

## API (for reference)

- `GET /api/health` — status, snippet count, models loaded
- `POST /api/predict` `{code, model?}` — language, confidence, top-3, model votes, length bucket
- `GET /api/models` — model list + headline metrics
- `GET /api/evaluate` — full evaluation (models, per-language, confusion matrix, by-length)
- `GET /api/dataset` — dataset stats
- `GET /api/samples/{language}` — a random sample snippet
- `POST /api/dataset/add` `{language, code}` — add a snippet, retrain
- `POST /api/dataset/upload` — CSV upload (`language,code`), retrain

## Honest limitations

- The built-in dataset is small (200 snippets) and written for the project;
  accuracy on real-world code will differ — upload a larger corpus for
  production use.
- Very short snippets (1 line) are genuinely ambiguous; the Length Lab
  shows this instead of hiding it.
- TypeScript without type annotations is indistinguishable from JavaScript;
  the model can only guess in that case.
- The app runs locally (no deployment); it is a single-process demo.
